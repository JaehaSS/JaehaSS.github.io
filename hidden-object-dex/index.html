숨은 물건 도감 업로더

Hidden Object Dex Uploader

숨은 물건 도감은 지퍼, 냉장고처럼 매일 쓰는 물건 속에 숨은 원리를 짧은 영상으로 설명하는 한국어 숏폼 채널입니다.

숨은 물건 도감 업로더(이하 "도구")는 채널 운영자가 직접 제작한 영상을 운영자 본인의 TikTok 계정 받은편지함에 초안으로 올리는 업로드 도구입니다. 영상 게시는 운영자가 TikTok 앱에서 직접 확인한 뒤 완료합니다.

주요 기능

  • TikTok 로그인으로 운영자 계정 연결
  • 완성된 영상을 TikTok 받은편지함에 초안으로 업로드
  • 업로드 처리 상태 확인

About (English)

Hidden Object Dex is a Korean short-form channel explaining how everyday objects work. Hidden Object Dex Uploader sends videos created by the channel operator to the operator's own TikTok inbox as drafts. The operator reviews and publishes each draft in the TikTok app.
